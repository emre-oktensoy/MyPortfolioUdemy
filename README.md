
MyPortfolio - Kişisel Portföy Projesi

Murat Yücedağ'a ait "Asp.Net Core ile Admin Panelli Dinamik Bir Portfolyo Geliştirelim Part (1 ve 2)" Udemy eğitimi ile geliştirilmiş bir projedir.

MyPortfolio, becerilerimi, projelerimi ve deneyimlerimi sergilemek için oluşturduğum kişisel bir portföy web sitesi olup, dinamik bir site yönetimi bulunmaktadır. Bu proje,modern web teknolojilerini kullanarak kullanıcı dostu ve görsel açıdan çekici bir deneyim sunmayı amaçlar.


Kullanılan Teknolojiler

    Frontend: HTML, CSS, JavaScript, Bootstrap
    Backend: .NET Core, Node.js
    Veritabanı: SQL Server
    Diğer: Entity Framework, LINQ
